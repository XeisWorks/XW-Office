# Unified Product Workflow

Der verbindliche Bauplan und die Task-Queue liegen bis zu einer bewusst geplanten
Konsolidierung unter `markdowns/unifying product flow/`. Dieses Verzeichnis enthält
die fortlaufenden, belegten Arbeitsnachweise für die Umsetzung, damit der Plan nicht
durch eine zweite, leicht abweichende Kopie auseinanderläuft.

- Bauplan: `markdowns/unifying product flow/BUILD_PLAN.md`
- Aufgaben: `markdowns/unifying product flow/TASK_QUEUE.yaml`
- Cover-Spezifikation: `markdowns/unifying product flow/COVER_SPEC.yaml`
- Fortschritt: `PROGRESS.md`
- Bestandsaufnahme T01: `CURRENT_STATE.md`
