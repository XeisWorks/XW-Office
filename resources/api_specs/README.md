# API Specs And External Schemas

Store downloaded or manually maintained API/specification files here.

Suggested layout:

- `sevdesk/` for sevDesk OpenAPI/YAML/JSON exports and endpoint notes.
- `wix/` for Wix API schemas, examples, and webhook payload references.
- `plc/` for Post Label Center specs, label schemas, and integration notes.
- `other/` for related third-party APIs.

When working on integrations, search this folder first before using older
copies from legacy repos or external downloads.
